## Theorems about possibility sets
1. $A$ know $E$ has occured iff a triusm that implies $E$ has occured
2. $P\{\omega\}$ is the smallest truism containing $\omega$
3. $A$ know that $E$ has occured in state $\omega$ iff $P\{\omega\}\subseteq E$

## Possibility sets
possibility sets formed a partition of $\Omega$

#### Lemma 3.
$\forall \omega'\in P(\omega), P(\omega') = P(\omega)$

### Theorem 4.
$\{P(\omega)|\omega\in \Omega\}$ is a partition of $\Omega$

proof.
first, it's obviously $\cup_\omega P(\omega) = \Omega$
next, we will prove that if $P(\omega_1)\neq P(\omega_2)$ then $P(\omega_1)\cap P(\omega_2) = \emptyset$:
- if not, then $\exists \omega_3\in P(\omega_1)\cap P(\omega_2)$
$\implies P(\omega_1)=P(\omega_2) = P(\omega_3)$ from Lemma 3, which cause a contradiction.

### Def.
consider 2 partitions of $\Omega$, $C$ and $D$.
we say $C$ is a refinement of $D$ if each set in $C$ is a subset of a set in $D$
